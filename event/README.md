# 🎁 내 홈페이지 자랑 이벤트 페이지

참가자가 직접 만든 홈페이지 **주소(URL)** 와 **간단한 소개**를 등록하면, 이벤트 페이지에 바로가기 카드가 생기고
접속한 모든 사람이 다른 참가자의 홈페이지를 눌러 구경할 수 있는 페이지입니다.
연락처는 비공개로 따로 저장되어, 이벤트 종료 후 추첨/당첨 안내에 사용합니다.

```
event/
├── index.html        # 이벤트 페이지 (이 파일 하나로 동작)
├── firestore.rules   # Firebase 보안 규칙
└── README.md
```

## 기능

- 📝 **등록**: 닉네임 · 홈페이지 URL · 소개(100자) · 연락처(비공개) 입력
- 🖼️ **갤러리**: 등록된 홈페이지가 카드로 표시되고, 누르면 새 탭으로 이동 (실시간 반영)
- 🔍 검색 / 최신순 · 등록순 · 랜덤 정렬
- 🚫 같은 주소는 한 번만 등록 가능
- ⏰ 등록 기간(시작일~마감일) 외에는 등록 폼 자동 숨김, D-day 표시
- 🎲 `index.html?admin` 으로 접속하면 추첨 버튼 표시
- 🌙 다크 모드 / 모바일 대응

## 1. 이벤트 정보 수정

`index.html` 의 `<script>` 맨 위 `EVENT` 부분만 바꾸면 됩니다.

```js
const EVENT = {
  title: "내가 만든 홈페이지를 자랑해 주세요!",
  startDate: "2026-10-17",
  endDate: "2026-11-10",
  announceDate: "2026-11-14",
  prizes: ["1등 (1명) · 에어팟 프로", ...],
};
```

## 2. Firebase 연결 (다른 사람들과 목록을 공유하려면 필수)

설정 전에는 **데모 모드**로 동작하며 등록 내용이 내 브라우저에만 저장됩니다.
모든 방문자가 같은 목록을 보려면 무료 Firebase Firestore를 연결하세요.

1. <https://console.firebase.google.com> 에서 **프로젝트 추가**
2. 왼쪽 메뉴 **빌드 > Firestore Database > 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, 프로덕션 모드)
3. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여넣고 **게시**
4. **프로젝트 설정(⚙️) > 일반 > 내 앱 > 웹(</>)** 으로 앱 등록 후 나오는 `firebaseConfig` 값을 복사
5. `index.html` 의 `firebaseConfig` 에 붙여넣기

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "my-event.firebaseapp.com",
  projectId: "my-event",
  ...
};
```

> `apiKey` 는 공개되어도 괜찮은 값입니다. 데이터 보호는 3번의 보안 규칙이 담당합니다.

## 3. 배포

홈페이지 만들 때와 똑같이 GitHub Pages 등으로 배포하면 됩니다.
이 저장소 기준으로는 `https://<아이디>.github.io/<저장소>/event/` 주소가 됩니다.

## 4. 추첨하기

1. `https://.../event/?admin` 으로 접속 → 하단 **추첨 (관리자)** 에서 인원 입력 후 **추첨하기**
2. 당첨자 카드에 표시된 `ID` 를 복사
3. Firebase 콘솔 **Firestore > `contacts` 컬렉션** 에서 같은 ID 문서를 열어 연락처 확인

> 추첨 화면은 공개 정보(닉네임·주소)만 보여주므로 누가 접속해도 연락처는 노출되지 않습니다.
> 연락처는 보안 규칙상 웹페이지에서 읽을 수 없고, 콘솔에서만 볼 수 있습니다.

## 운영 팁

- 부적절한 등록은 Firebase 콘솔에서 `entries` 의 해당 문서를 삭제하면 바로 사라집니다.
- 이벤트가 끝나면 `contacts` 컬렉션을 삭제해 개인정보를 파기하세요.
